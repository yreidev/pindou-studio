# 标题字体

`examplebrand-display.woff2` 是 [霞鹜文楷 Light v1.520](https://github.com/lxgw/LxgwWenKai/releases/tag/v1.520) 的字符子集，由 `scripts/build-font-subset.mjs` 生成；`src/styles/_font.scss` 内嵌同一份字体。字符清单在 `examplebrand-display.charset.txt`。

字体及其子集依 SIL Open Font License 1.1 分发，上游版权声明与完整许可见 [LICENSE.OFL.txt](LICENSE.OFL.txt)。仓库自有代码的使用限制不适用于这些字体文件。
