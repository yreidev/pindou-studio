# 做图纸的图标

取自 Lucide（ISC，见 LICENSE.lucide，lucide-react 0.468.0），只换了颜色：深色悬浮工具栏上用 #f7f5f0。
ratio = crop、rotate = rotate-cw、flip = flip-horizontal-2、tone = sliders-horizontal、reset = rotate-ccw。
cut = scissors（抠图，2026-10-22 加，取自 lucide-react 1.16.0，同为 ISC）。
SVG 是原稿，页面用的是 72 × 72 的透明 PNG（小程序原生图片兼容），只被做图纸分包引用。
